# Imported gameplay assets

All 106 new gameplay PNGs supplied under `bin` are copied into matching runtime paths under `res`. The build packages `res`, so the game runs from the JAR without reading `bin`.

| Runtime group | PNGs | Use |
| --- | ---: | --- |
| Monster | 54 | Animated green/red slimes, bats, directional orc movement/attacks, and both skeleton-lord phases |
| NPC | 11 | Direction-facing Runekeeper, animated merchant, and the movable pressure-plate rock |
| Player/Attacking sprites | 24 | Two attack frames in four directions for sword, axe, and pickaxe |
| Player/Guarding sprites | 4 | Directional shield guard poses |
| Projectile | 9 | Directional two-frame fireballs and thrown rocks |
| Tiles_Interactive | 4 | Axe-cut dry trees, remaining stumps, pickaxe-broken walls, and latched metal plates |

The captions, subtitle translations, tutorial documents, and old compiled outputs in `bin` are not gameplay resources and are not packaged. Original source files in `bin` are unchanged.
