# True Adventure 2.0.1

**True Adventure** is a 2D pixel adventure where you explore five connected maps, find four lost seals, and face the Skeleton King. Fight monsters, solve puzzles, and discover new paths as you travel from Whisperwood to King's Tomb.

## The adventure

- Explore Whisperwood, Sun Temple, Lost Vault, Ember Village, and King's Tomb.
- Fight slimes, bats, and orcs with your sword and shield, then take on the final boss.
- Learn fireball and use an axe and pickaxe to open blocked paths.
- Solve rune puzzles, move rocks, talk to characters, and buy potions for your journey.

## Download and play on Windows

**[Download True Adventure for Windows](https://github.com/aliahmed235/2D-Adventure-Game/releases/download/v2.0.1/True-Adventure-2.0.1-Windows-x64.zip)** — Windows 10/11, 64-bit.

**Java is included. You only need the Windows ZIP.** No Java installation or game installer is required.

1. Download **True-Adventure-2.0.1-Windows-x64.zip** using the link above.
2. Right-click the ZIP, choose **Extract All**, and finish extracting it.
3. Open the extracted **True Adventure** folder.
4. Double-click **True Adventure.exe**.
5. Enter your name and press **Enter** to begin.

Keep the **app** and **runtime** folders beside the EXE. Run the game from the extracted folder.

Press **H** for controls, **Esc** to pause, and **F11** to switch fullscreen on or off.

**Progress is not saved after you close the game.**
