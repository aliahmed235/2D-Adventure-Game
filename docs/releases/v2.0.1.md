# True Adventure 2.0.1

The game is now called **True Adventure**. The game window, native launcher, and downloadable packages use the new name.

## Download and play

For Windows 10/11 (64-bit), **[download True Adventure](https://github.com/aliahmed235/2D-Adventure-Game/releases/download/v2.0.1/True-Adventure-2.0.1-Windows-x64.zip)**. This is the player download, including for anyone without Java installed. In the assets below, choose **Download and play - Windows 64-bit - Java included**.

1. Extract the complete ZIP.
2. Open the **True Adventure** folder.
3. Double-click **True Adventure.exe**.

**Java is included.** No separate Java installation or game installer is needed. Keep the **app** and **runtime** folders with the EXE. Players need the Windows ZIP only.

Explore five connected maps: Whisperwood, Sun Temple, Lost Vault, Ember Village, and King's Tomb. This version includes combat, tools, spells, NPCs, puzzles, and the final boss, plus player names, the compact HUD, inventory, help, and fullscreen with **F11**.

Progress and names last for the open game session. Closing the game ends that run.
