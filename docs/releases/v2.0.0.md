# The Sunken Seal 2.0.0

A bigger adventure, with five maps and a new download that runs without installing Java.

## Download and play

For Windows 10/11 (64-bit), download **The-Sunken-Seal-2.0.0-Windows-x64.zip** from the assets below.

1. Extract the complete ZIP.
2. Open **The Sunken Seal**.
3. Double-click **The Sunken Seal.exe**.

Java is included. No separate Java installation or game installer is needed. Keep the **app** and **runtime** folders with the EXE.

## New in this release

- Five connected maps: Whisperwood, Sun Temple, Lost Vault, Ember Village, and King's Tomb.
- Slimes, bats, orcs, and a two-phase Skeleton King boss.
- Sword combat, shield blocking, fireballs, axes, pickaxes, and breakable paths.
- NPC dialogue, potion trading, rune puzzles, and a rock-and-plate challenge.
- Player names, a smaller HUD, a field-journal inventory, and simpler instructions.
- Fullscreen with **F11**, a mouse/keyboard pause menu, and **H** for help.

Progress and names last for the open game session. Closing the game ends that run.

## Other downloads

- **The-Sunken-Seal-2.0.0.jar** is for users who already have Java 17 or newer.
- **SHA256SUMS.txt** contains download checksums.
